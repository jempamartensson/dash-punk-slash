Icons — isometric file types

Isometric file icons

These are new icons drawn the way IRIX drew its own. Everything sits on one 2:1 isometric grid, with black outlines, three-tone shading and a drop shadow on a flat base. Click an icon to select it, and it turns yellow, as it did on IRIX.

One projectionHorizontal edges rise one unit for every two across, so every icon shares a vanishing logic and they tile together on the desktop.

Circles mean spheresA circle drawn face-on reads as a ball. IRIX kept circles for spheres, and so does this set. The assistant orb is the only round shape.

Three tones per materialThe top face is lightest, the left face is the base colour and the right face is darkest. The light always comes from the upper left.

State is colourSelected icons turn yellow. A drop target turns royal blue. Open and closed variants come later for folders and packages.

Schemes — colour scheme browser

Four schemes

IRIX coloured every app from about 40 named roles, such as basic background, text field, select fill and active window. We do the same. One small token file per scheme drives Hyprland, waybar, the terminal, the launcher and the Qt apps. Slate is what the step 1 install already ships.

Notes — research and build plan

What made the IRIX desktop look the way it did

  • The Indigo Magic Desktop shipped with IRIX 5.1 on the Indy in 1993. It was renamed the IRIX Interactive Desktop in IRIX 6.5 (1998). It was built on Motif, with the 4Dwm window manager.
  • Icons were vector files (.fti, drawn in IconSmith), all in one isometric view. The design guide says horizontal lines go up 1 unit for every 2 across, and that circles should be kept for spheres.
  • Each icon was built from parts: a generic "magic carpet" base plus a badge, with separate open and closed states. The body used a special white "Icon Color", the lines a special black "Outline Color", and a contrasting "Shadow Color" sat underneath.
  • Icons turned yellow when selected and royal blue when something was dropped on them.
  • Schemes drove every colour from about 40 named roles (basicBackground, textFieldBackground, selectFillColor, wMActiveBackground...). IRIX 6.5 came with around 30 schemes, including Lascaux, Rio, Gotham, Milan and Mendocino.
  • The distinctive controls were thumbwheels for continuous values, bevelled Motif buttons, and a red outline while you dragged a window.
  • MaXX Interactive Desktop is a living Linux port of this desktop. SGI's own scheme files are under a special licence, so the palettes here are original, not copies.

How this becomes real

  • One token file per scheme (themes/slate.toml) is the single source. A small generator writes the Hyprland colours, waybar CSS, foot, fuzzel and mako config, plus a Qt stylesheet and palette for usdview and the other PySide tools.
  • usdview is restyled inside our USD rez package. Usdviewq ships its own Qt stylesheet, and we swap it for the generated one. A small usdview plugin adds the scheme switcher. The thumbwheel dolly is a stretch goal.
  • Icons are SVGs built from this page's isometric generator. They get packaged as a freedesktop icon theme, with MIME types for .usd .usda .usdc .usdz .vdb .exr .abc and rez packages.
  • Fonts: Terminus in the shells and a Helvetica-style UI font, Nimbus Sans (a free Helvetica metric clone), in panels.
  • Viewport: Hydra Storm on the Radeon 8060S via OpenGL. Whether it works well is checked on the real machine in step 2.

Your call

  • Which scheme should be the default? Slate, Teal, Granite or Lavender, or a mix.
  • Should the icons look like this (flat, three tones) or be more detailed, with gradients like late IRIX?
  • What else should get icons first? Houdini .hip, Nuke .nk, Alembic, render jobs?
